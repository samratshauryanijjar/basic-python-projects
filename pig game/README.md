# 🎲 Pig Game

A simple terminal-based multiplayer Pig dice game built with Python.

## 🎮 How It Works

- Supports **2 to 4 players**
- Players take turns rolling a dice
- Each roll gives a random number between **1 and 6**
- If a player rolls **1**, their score for that turn becomes **0** and their turn ends
- Players can keep rolling to increase their turn score
- The first player to reach **50 points** wins the game

## 🛠️ Built With

- Python
- `random` module

## ▶️ How to Run

1. Clone this repository
2. Make sure Python is installed
3. Run:
