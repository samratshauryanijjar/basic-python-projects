# 🧮 Math Quiz Game

A simple Python math quiz game that generates random arithmetic problems and tracks how long you take to complete them.

## 🎮 How It Works

- Press Enter to start the game
- Solve **10 random math problems**
- Problems use:
  - Addition `+`
  - Subtraction `-`
  - Multiplication `*`
- Numbers range from **3 to 12**
- If your answer is wrong, you can keep trying until you get the correct answer
- Your total completion time is displayed at the end

## 🛠️ Built With

- Python
- `random`
- `time`

## ▶️ How to Run

1. Clone this repository
